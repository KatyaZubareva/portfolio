Echo Blade

A real-time game that turns any webcam into a controller using OpenCV feature matching and a WebSocket bridge to UE5.

Understanding the data

No markers. Just the sword.

Colour masks broke in bad light and ArUco markers looked out of place on a toy sword.

So the tracker learns the sword itself: ORB features from a photo are matched in every frame.

The model

Real-time vision for a physical game.

A homography fitted with RANSAC gives the sword centre and angle; a Python WebSocket server streams them into Unreal Engine 5.

Inside the game a C++ actor maps every message to the sword, while Motion Warping lines up the attacks.

The challenge

Motion control shouldn't feel like waiting for the screen.

Webcam tracking usually adds lag, loses the hands in fast swings and breaks when the lighting changes.

The goal was to build a tracker that runs in real time on a laptop and keeps the sword in sync with the player.
